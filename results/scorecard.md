# Scorecard

Generated by `python -m src.scorecard` from the result CSVs. Do not edit by hand.

**How to read it.** *Right object*: clips where the text prompt picked the right thing. *Mask accuracy*: overlap with the true object. *Fill score*: 0 = object still there, 100 = identical to the real background. *Steadiness*: flicker compared with the real video (1.0x = as steady as real footage). *Speed*: on a MacBook (M5); seconds per frame (a 60-frame clip takes 60 times that).
